Retail Sales EDA
Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to understand sales and profit patterns and identify useful business insights.

Objectives:
Analyze overall sales and profit performance
Study year-wise sales and profit
Analyze sales by category and segment
Examine monthly and quarterly sales trends
Analyze relationships between numerical variables
Identify useful patterns and insights from the dataset

Tools & Technologies
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook 

Dataset:

The analysis uses the Sample Superstore dataset, which contains information about retail orders, including sales, profit, 
discount, category, segment, and dates.

Analysis Performed
The project includes:

Data loading and inspection
Data cleaning
Descriptive statistics
Year-wise Sales and Profit analysis
Category-wise analysis
Segment-wise analysis
Monthly sales analysis
Quarterly sales analysis
Correlation analysis
Data visualization

Visualizations:
The project includes visualizations for:
Monthly Sales
Quarterly Sales
Category-wise Sales
Correlation Heatmap

Project Structure:
The project contains:

Retail_Sales_EDA.ipynb — Complete exploratory data analysis notebook
Sample_superstore.csv — Dataset used for the analysis
category_sales.PNG — Category-wise sales visualization
correlation_heatmap.PNG — Correlation heatmap
monthly_sales.PNG — Monthly sales visualization
quaterly_sales.PNG — Quarterly sales visualization

Key Insights:
The analysis helps understand sales and profitability across different years, categories, and customer segments and provides
a basic overview of retail business performance.
