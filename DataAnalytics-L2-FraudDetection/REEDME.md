# Fraud Detection

## Overview

This project uses machine learning to detect fraudulent credit card transactions from transaction data.

## Dataset

The dataset contains transaction features along with a `Class` column, where:

* `0` represents a normal transaction
* `1` represents a fraudulent transaction

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Methodology

* Data exploration and preprocessing
* Class distribution analysis
* Feature scaling
* Stratified train-test split
* Random Forest classification
* Performance evaluation using Accuracy, Precision, Recall, F1-score and ROC-AUC
* Confusion matrix and feature importance analysis

## Conclusion

The Random Forest classifier was trained and evaluated to identify fraudulent transactions. The model performance was assessed using multiple classification metrics, with particular importance given to fraud detection performance.
