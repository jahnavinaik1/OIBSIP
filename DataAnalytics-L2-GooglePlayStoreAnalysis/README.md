# Google Play Store Analysis

## Overview

This project analyzes Google Play Store data to identify trends in app categories, ratings, installations, reviews, pricing, and content ratings.

## Dataset

The project uses Google Play Store app data containing information about app names, categories, ratings, reviews, installs, prices, genres, and Android versions.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Data cleaning and preprocessing
* App category analysis
* Rating distribution analysis
* Free vs paid app analysis
* Installation analysis
* Review analysis
* Price analysis
* Content rating analysis
* Genre analysis
* Android version analysis
* Correlation analysis

## Conclusion

The analysis provides insights into app popularity, user ratings, installations, pricing patterns, and category trends in the Google Play Store.
