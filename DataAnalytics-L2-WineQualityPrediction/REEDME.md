# Wine Quality Prediction

## Overview

This project predicts wine quality using machine learning based on physicochemical properties of red wine.

## Dataset

The project uses the **Wine Quality dataset** containing features such as acidity, sugar, chlorides, sulphates, alcohol, and quality.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning Models

* Random Forest Classifier
* SGD Classifier
* Support Vector Classifier (SVC)

## Analysis

The project includes:

* Data exploration and quality distribution
* Correlation analysis
* Feature distribution analysis
* Model training and evaluation
* Confusion matrices
* Model accuracy comparison
* Feature importance analysis

## Conclusion

The performance of the three classification models was compared using accuracy and classification metrics. The best-performing model was identified based on the evaluation results.
